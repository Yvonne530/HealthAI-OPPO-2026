# 数据缓存机制使用说明

## 📦 功能概述

从 v10.0 开始，RehabGuardian 支持**智能数据缓存**机制，显著减少重复训练时的数据加载时间。

### ✨ 主要特性

1. **自动缓存**：首次加载 `.b3d` 文件后自动保存处理后的样本
2. **智能验证**：检测数据文件变化，自动失效旧缓存
3. **配置一致性检查**：确保缓存参数（FPS、min_frames 等）与当前配置一致
4. **快速恢复**：后续训练直接从缓存加载，无需重新解析 `.b3d` 文件

---

## 🚀 使用方法

### 1️⃣ 默认使用缓存（推荐）

直接运行训练脚本，系统会自动使用缓存：

```bash
bash scripts/pretrain_real.sh /mnt/d/Camargo2021_Formatted_No_Arm
```

**首次运行**：
- 完整加载所有 `.b3d` 文件（约需数分钟）
- 自动保存到 `.cache/b3d_cache_*.pkl`
- 显示：`[B3DLoader] 缓存已保存：xxx (XXXXX 帧)`

**后续运行**：
- 直接从缓存加载（通常只需几秒）
- 显示：`✓ [B3DLoader] 从缓存加载 XXXXX 帧`

---

### 2️⃣ 强制重新加载（清除缓存）

当数据文件发生变化或需要重新预处理时：

#### 方法 A：使用命令行参数

```bash
python main.py --mode train --clear-cache --config configs/config.yaml
```

或在你的脚本中添加 `--clear-cache` 参数。

#### 方法 B：使用清除缓存脚本

```bash
# 清除默认目录的缓存
bash scripts/clear_cache.sh

# 清除指定目录的缓存
bash scripts/clear_cache.sh /path/to/your/data
```

---

### 3️⃣ 在配置文件中控制缓存

编辑 `configs/config.yaml`：

```yaml
data:
  use_cache: true   # 启用缓存（默认）
```

设置为 `false` 可临时禁用缓存。

---

## 📂 缓存文件位置

缓存保存在数据目录下的 `.cache/` 文件夹：

```
/mnt/d/Camargo2021_Formatted_No_Arm/
└── .cache/
    └── b3d_cache_<hash>.pkl
```

其中 `<hash>` 是基于数据目录路径生成的 MD5 哈希值前 8 位。

---

## 🔍 缓存验证机制

系统在加载缓存前会进行以下验证：

1. **文件签名校验**：检查所有 `.b3d` 文件的修改时间和大小
2. **配置一致性校验**：确认 `target_fps`、`min_frames`、`vel_diff_threshold` 等参数一致
3. **完整性校验**：验证缓存文件的完整性

如果任何一项失败，系统会自动重新加载原始数据并更新缓存。

## 🛠️ 故障排查

### Q: 缓存加载失败怎么办？

A: 系统会自动回退到原始数据加载模式，并记录警告信息。你可以：
1. 检查缓存文件是否损坏
2. 手动删除 `.cache/` 目录
3. 使用 `--clear-cache` 参数强制重新加载

### Q: 如何确认缓存是否生效？

A: 查看日志输出：
- ✅ 缓存生效：`✓ [B3DLoader] 从缓存加载 XXXXX 帧`
- ❌ 缓存未命中：`[B3DLoader] 开始从 XX 个文件加载...`

### Q: 缓存文件太大怎么办？

A: 缓存文件大小约等于原始数据的 1.2-1.5 倍（包含所有处理后的特征）。如果空间不足：
1. 定期使用 `scripts/clear_cache.sh` 清除缓存
2. 在配置文件中设置 `use_cache: false`

## 📝 最佳实践

1. **首次训练**：预留足够时间让系统构建缓存
2. **日常开发**：享受缓存带来的速度提升
3. **数据更新后**：记得使用 `--clear-cache` 刷新缓存
4. **分享项目**：将 `.gitignore` 中的 `.cache/` 目录排除

---

## 🔒 注意事项

- ✅ 缓存机制默认启用，无需额外配置
- ✅ 缓存会自动失效，不用担心数据不一致
- ✅ 支持多进程安全读取
- ⚠️ 不要手动编辑 `.pkl` 缓存文件
- ⚠️ 缓存文件较大，注意磁盘空间

## 📚 技术细节

缓存文件格式：

```python
cache_data = {
    "signature": "文件签名（用于检测变化）",
    "samples": [...],      # 所有 RGSample 对象
    "file_list": [...],    # .b3d 文件列表
    "config": {            # 加载配置
        "target_fps": 60,
        "min_frames": 30,
        "vel_diff_threshold": 0.5,
    }
}
```

使用 Python 的 `pickle` 模块序列化，协议版本为 `HIGHEST_PROTOCOL`。
